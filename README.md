# Bài 2 : Xử lý lỗi thư viện mã nguồn mở bằng GitHub Issues

## Đặc điểm bình luận ưu tiên đọc
- Nhiều reactions như Thumbs Up hoặc Heart vì đã được nhiều người áp dụng thành công.
- Có mã nguồn cụ thể và mô tả rõ môi trường máy tính.

## Khái niệm Workaround và lý do không chờ bản cập nhật chính thức
- Workaround là giải pháp tạm thời giúp khắc phục lỗi ngay để tiếp tục công việc.
- Không đợi bản cập nhật vì thời gian phát hành vá lỗi lâu, làm gián đoạn tiến độ học tập và dự án.
